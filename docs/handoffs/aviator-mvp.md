# Aviator MVP — локальная передача, 01.10.2026

## Выполнено

Создан исходный iOS 17+ проект Aviator.xcodeproj с общей схемой Aviator, unit/UI targets и конфигурациями MOCK/LIVE. Четыре экрана, нативная навигация поиска и избранного, поиск аэропорта по русскому городу/IATA, выбор шести месяцев, бюджет 5–100 тысяч рублей, прямые рейсы, дополнительные сочетаемые фильтры, минимум по городу после фильтров, стабильная сортировка, детали и переход на Aviasales. Локальные фотографии десяти направлений и побережья, атрибуция в credits и приложении; адаптация Dynamic Type, VoiceOver labels, отсутствие принудительных анимаций при Reduce Motion. SwiftData хранит снимок маршрута/дат/цены/источника, не создаёт дублей, обрабатывает ошибки и прошедшие даты.

Backend FastAPI с управляемым httpx.AsyncClient, точной Decimal-нормализацией рублей в копейки, официальным справочником, аэропортовыми зонами и правилами будущих выходных. Пагинация 10 страниц/20 секунд, retry временных ошибок, Retry-After и upstream rate headers, частичные ответы, TTL/LRU-кеш, singleflight, пользовательский и upstream лимитеры. Три endpoint, без токена health и справочник работают; LIVE честно ошибается. Обычные ссылки по документированному формату; партнёрские — только готовые точные сопоставления из официального генератора. Локальная аналитика без персональных данных/URL/секретов.

## Решения и ограничения

- Денежный контракт — price_minor/max_budget_minor, целые копейки RUB, граница включительна. Повышенная точность источника округляется вверх до копейки. Некорректная валюта не конвертируется.
- MOCK поддерживает только SVO, не подменяет аэропорт в фикстурах. Даты динамические, для smoke test фиксировано время 01.10.2026.
- LIVE никогда не заменяется MOCK. Endpoint Data API не подтверждает класс тарифа: в интерфейсе предупреждение, внешний поиск эконом для одного взрослого. Полное выполнение гарантии эконом-класса этим источником не подтверждено.
- MARKER не превращается в выдуманный affiliate-параметр. Опциональный PARTNER_LINKS_FILE содержит готовые ссылки из кабинета. Генерация произвольной партнёрской ссылки и атрибуция не подтверждены.
- Документированный URL с DDMM не содержит года. Поиск ограничен ближайшими шестью месяцами; переход через год требуется проверить у партнёра.
- Backend локальный, один процесс. Публичное размещение, оплата, регистрация и прочие исключённые функции отсутствуют.

## Реально выполненные проверки

- Python 3.14.7; установлены зависимости в локальный .venv. `cd backend && ../.venv/bin/python -m pytest -q`: **51 passed**, одно предупреждение Starlette о будущем переходе тестового клиента с httpx на httpx2; ошибок тестов нет.
- Swift 6.3.3 Command Line Tools: `swift run AviatorChecks` с временными каталогами кеша — **57 успешных поведенческих проверок**, включая MOCK, копейки, выходные/границы года, фильтры, состояния, поздний ответ, ссылки, инъекцию хранилища и Python JSON-контракт в LIVE URLSession.
- SwiftData не заменён mock-реализацией в приложении. Portable runner проверяет FavoritesViewModel с внедрённым memory store, что **не подтверждает** дисковую персистентность SwiftData. Для неё написан iOS unit test повторного открытия контейнера.
- Проверка типов Foundation-сервисов через swiftc прошла. Синтаксис всех Swift исходников/тестов проверен swiftc -frontend -parse.
- `plutil -lint` проекта и обоих Info.plist; `scripts/verify_project.py`: три target, общая схема, членство всех Swift-файлов, наличие ресурсов, одинаковый справочник, отсутствие ATS-исключений в Release — успешно.
- Backend реально запускался uvicorn на 127.0.0.1:8009: /health — 200, LIVE без токена — 503 с русской ошибкой конфигурации; затем сервер остановлен.
- Фотографии визуально просмотрены, неподходящие первоначальные кадры заменены; финальные фотографии локальные и с записанными лицензиями.
- Проверка diff/секретов/старых названий в новых файлах — выполнена; личные .env не добавлены.
