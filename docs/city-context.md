# Профиль, показатели и подробности города

Реализация задачи #18, расширенный запрос 08.10.2026. Ветка `issue-18-personal-city-rating`, основа — цепочка приложения до PR #20. Это расширение существующего рейтинга, не новый независимый рейтинг страны.

## Структура приложения

Четыре вкладки: «Куда поехать» (рейтинг и подборки), «Поиск», «Сравнение», «Избранное». В «Куда поехать» доступен профиль: гражданство/паспорт, страна проживания, шесть интересов и предпочтение цены/дороги. Настройки и города без конкретного рейса сохраняются локально. Страны не угадываются по языку устройства. При открытии контекста сервер получает только страны, интересы, город и даты. Новые внешние API получают координаты и даты либо страну направления; гражданство туда не передаётся автоматически. Переход к Sherpa передаёт выбранный паспорт в URL после нажатия пользователя.

Настройки основного поиска сохраняются между запусками. Прошедшие даты и месяц вне доступного диапазона сбрасываются, аэропорт и бюджет сохраняются. Во время повторного поиска и при ошибке доступна предыдущая выдача с предыдущими условиями. Подробности и возврат в список сохраняют состояние SwiftUI. Активные дополнительные фильтры перечислены над выдачей и снимаются одним нажатием. В рейтинге есть фильтр наличия хотя бы одного варианта в пределах бюджета пользователя; средняя/медиана по исходной выборке при этом не меняются. Вкладка сравнения показывает число выбранных поездок.

## Разделение оценок

- Оценка перелёта `flight-v1.0`: прежние 65% цены и 35% дороги.
- Полная поездка `trip-v1.0`: прежние обязательные расходы/дорога/безопасность/условия. При пропусках итога нет.
- Подбор по предпочтениям: цена/дорога/совпадение редакционных интересов. Баланс — 40/35/25; дешевле — 60/20/20; меньше дороги — 20/60/20; с семьёй — 30/50/20. Все три компонента обязательны, DEMO не получает LIVE-балл. Серьёзное предупреждение из проверенной модели блокирует подбор. Семейный профиль меняет вес дороги, не оценивает детей, детские тарифы или жильё.

Сортировки: балл выбранной модели, средняя цена, дорога, имя, интересы, HDI и предпочтения. Новые контекстные источники не превращаются автоматически в численную безопасность или полный туристический бюджет. Предупреждения FCDO видны отдельно и не входят в персональную сумму. HDI не считается безопасностью. Совпадение интересов — доля выбранных тегов, присутствующих в редакционном описании; отсутствие тега не доказывает отсутствие занятия в городе.

Среднее, медиана, диапазон и число уникальных найденных предложений показаны вместе. Дубли различаются также по источнику. Эти показатели описывают конкретную выборку кешированных цен и общие условия, не весь рынок.

## Карточка города

Редакционные описания 25 городов: Москва, Петербург, Сочи, Казань, Стамбул, Анталья, Тбилиси, Ереван, Баку, Дубай, Париж, Рим, Барселона, Берлин, Амстердам, Прага, Лондон, Нью-Йорк, Лос-Анджелес, Сан-Франциско, Будапешт, Вена, Лиссабон, Афины, Бангкок. Есть интересы, идеи прогулок, районы для изучения, ориентир длительности и официальные туристические порталы. Это редакционные предложения, не расписание/наличие/тарифы. Для остальных городов выводится отсутствие описания.

Показатели раскрываются отдельно: погода/сезон, магазинная корзина, предупреждения, въезд, HDI. Видны источник, период/год и отсутствие данных. HDI доступен из локального официального снимка также без сети. Точное полезное время после сна/трансфера/заселения не вычисляется без личного расписания и подтверждённых трансферов; виден исходный расчёт времени на месте.

## Endpoint и источники

`POST /api/v1/cities/insights`: `city_code`, `citizenship?`, `residence?`, `start_date`, `end_date`, `interests[]`. Интервал до 60 дней, коды проверяются. Возвращает `guide`, `weather`, `basket`, `safety`, `hdi`, `entry`, `interest_score`, `matched_interests`, `fetched_at`. Последнее — момент сборки контекста; внешние данные кешируются до часа. Поиск авиабилетов от этих запросов не зависит. Ошибка отдельного источника сохраняет другие показатели. Сервер ограничивает параллелизм четырьмя, запрос источника — четырьмя секундами, кеш — 256 ключами; 429 включает паузу для хоста. Неизвестный город не вызывает внешних запросов. URL источников фиксированы, пользователь не задаёт URL.

## Магазинная корзина

Фиксированный набор: рис 1 кг, хлеб 0,5 кг, яйца 10 шт., молоко 1 л, яблоки 1 кг, помидоры 1 кг, куриная грудка 1 кг, йогурт 0,5 кг. Это сравнительный набор покупок, не медицинская рекомендация, суточный рацион или стоимость ресторанного питания.

Для товара используется медиана нормализованных цен, минимум пять наблюдений из трёх магазинов. Показаны количества, число наблюдений/магазинов и стоимость в местной валюте. Если покрытие частичное, отдельно показана сумма только подтверждённых товаров, явно не полная корзина. Полная сумма появляется только при наличии всех восьми товаров; неизвестные цены не заменяются нулями и не включаются в полный бюджет отдыха. Конвертация в рубли не выполняется без отдельного проверенного валютного источника. Выборка ограничена и не претендует на рыночную среднюю.

Реальный сквозной пилот 08.10.2026: Париж, Стамбул, Петербург → HTTP 200, погода доступна, HDI 2023 доступен. Париж: хлеб 21 наблюдение/11 магазинов, молоко 7/6, помидоры 6/6, йогурт 21/9; остальные категории недостаточны. Стамбул: один йогурт; Петербург: подходящих наблюдений нет. Во всех трёх полная корзина неизвестна. FCDO: Париж без общего alert-флага, Турция — предупреждение о частях страны, Россия — о всей стране; это не персональная оценка для российского паспорта.

## Что ещё требует доступа/данных

1. Автоматические визовые правила для всех паспортов: договор и ключ поставщика; нужен учёт транзита, срока паспорта и имеющихся виз. Ключи в чат не передавать.
2. Полная корзина для пилотных городов: дополнительный лицензированный источник цен либо больше проверенных наблюдений. Текущий API не обеспечивает покрытие.
3. Жильё на конкретные даты, ресторанное питание, местный транспорт/трансферы и курсы валют: подтверждённые источники. Нет оснований объявлять полный LIVE-бюджет готовым.
4. Сопоставимая безопасность городов: отдельные данные о кражах/насилии и проверенная методика. FCDO и HDI их не заменяют.
5. Пилот с физическим iPhone, ручной VoiceOver и обратная связь пользователей остаются этапами приёмки.
