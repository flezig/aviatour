## Поиск

GET https://api.travelpayouts.com/aviasales/v3/prices_for_dates; токен исключительно в X-Access-Token. Параметры: origin (IATA аэропорта или города при выборе «все аэропорты»), departure_at=YYYY-MM, one_way=false, currency=rub, market=ru, direct=true/false, unique=false, sorting=price, limit=1000, page=1…10. Возврат не ограничен месяцем: фильтруются пары местных дат продолжительностью 2/3 календарных дня. Параметра «выходные» нет. Дата вылета сравнивается с внедрённым временем.

currency задаёт единицы исходного price (рубли); парсер JSON использует Decimal. Перевод в копейки — Decimal×100 с ROUND_CEILING: излишняя точность округляется вверх до копейки. Цена в иной явной валюте исключается с incomplete; иная валюта всего ответа — ошибка. При отсутствии currency используется документированная семантика запроса currency=rub. Никаких курсов и Double/float в денежных расчётах.

Документированный default market для этого endpoint — ru. Конфигурация отдельно от валюты, отсутствующее/пустое значение использует ru. Не выводится из языка интерфейса.

Ответ подтверждает origin_airport/destination_airport, departure_at/return_at, transfers/return_transfers, duration_to/duration_back, link. Код города не подменяет аэропорт. При поиске всех аэропортов сверяем city_code фактического origin_airport со справочником; в предложении сохраняем конкретный аэропорт. Если аэропорт либо его часовой пояс отсутствует в справочнике, запись исключается с предупреждением. Offset времени преобразуется в IANA-зону аэропорта; неизвестные пересадки/длительности остаются null. Обязательны даты с offset, положительная цена и безопасная ссылка. ID — hash маршрута, дат, авиакомпании, номера рейса и источника, без цены.

**Ограничение класса:** у prices_for_dates нет документированного параметра класса или гарантии класса записи. Мы не отправляем выдуманный trip_class; явно неэкономические записи исключаются. Для остальных экономический класс LIVE нельзя подтвердить этим endpoint, и интерфейс предупреждает об этом. Data API не подтверждает условия багажа, доступность к покупке или цену после перехода.

limit=1000 — документированный максимум; выбран для покрытия большего количества находок в ограниченном числе запросов. Общий предел 10 страниц/20 секунд, timeout одной попытки 5 секунд, до трёх попыток только для timeout/network/429/5xx. Retry-After поддерживает секунды и HTTP-date. Учитываются X-Rate-Limit-Remaining/Reset; локальный upstream limiter 550/min ниже документированных 600/min. Первая ошибочная страница — ошибка; последующая — частичный ответ. Некорректные строки и достигнутые пределы явно помечают incomplete. Даже исчерпание страниц не означает полный перечень рейсов: источник содержит кеш найденных пользователями цен за 48 часов.

## Ссылки

Обычный поиск: https://www.aviasales.com/search/PARAMS. PARAMS = IATA отправления + DDMM + IATA назначения + DDMM возврата + 1 (один взрослый, эконом по документированной семантике отсутствия буквы класса). API link дополняется https://www.aviasales.com и проверяется: только HTTPS, точные допустимые домены, путь /search/, без credentials/чужого порта.

Документированный формат ссылок не кодирует год. MVP предлагает только ближайшие шесть месяцев, что ограничивает неоднозначность, но реальную интерпретацию дат при переходе через год нужно проверить у партнёра; приложение показывает полные годы. Прошедшие предложения не открываются как актуальные.

Документация требует превращать готовый маршрутный URL в партнёрский через генератор в кабинете Travelpayouts. Не добавляем выдуманные параметры или MARKER вручную. Опциональный PARTNER_LINKS_FILE — JSON `{ "https://www.aviasales.com/search/…": "https://tp.media/…" }` с точными маршрутными ссылками, заранее сгенерированными в кабинете. Разрешены tp.media/avs.io по HTTPS. Значение MARKER само по себе ничего не активирует. При отсутствии сопоставления открывается обычная ссылка. Автоматический генератор произвольных партнёрских ссылок не реализован, поскольку публичный подтверждённый механизм для данного случая не найден. Атрибуция требует проверки перехода и отчётов кабинета; здесь она не проверена.

## Справочник

Локальные снимки https://api.travelpayouts.com/data/ru/airports.json, cities.json, countries.json от 01.10.2026. Используем только flightable=true, iata_type=airport, с документированным city_code. Русские города, страна и аэропортовая IANA-зона берутся из справочника. 3682 записи; один и тот же JSON в iOS/backend. Перегенерация: загрузить три официальных JSON в /tmp/aviator-{airports,cities,countries}.json и выполнить scripts/build_catalog.py.

## Расширенный поиск, 04.10.2026

[Официальный контракт prices_for_dates](https://support.travelpayouts.com/hc/en-us/articles/203956163-Aviasales-Data-API) подтверждает точные даты `YYYY-MM-DD`, `destination`, код авиакомпании, номер рейса и длительность каждого плеча. Отдельного подтверждённого времени прилёта и оператора каждого сегмента в используемом ответе нет; клиент показывает расчёт по длительности с явной подписью. Названия — локальный снимок [официального справочника](https://api.travelpayouts.com/data/airlines.json), 1159 кодов, дата 04.10.2026.

Первый запрос 2,565 с, изменение бюджета на 20 000 ₽ и фильтра прямых рейсов — 0,002 с с повторным использованием исходного кеша. Точные даты 09–12.10.2026, SVO → ULV: HTTP 200, 3 варианта, даты и фактический аэропорт совпали, неполнота false, 0,225 с. Это разовый замер на локальном backend и кешированные цены, не гарантированное время сети или доступность покупки.
