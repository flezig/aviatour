# Aviator backend

Python 3.12+, один процесс. Из корня репозитория:

```sh
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
cp backend/.env.example backend/.env
cd backend
../.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Настоящий TRAVELPAYOUTS_API_TOKEN добавляется только в backend/.env. Без него health и справочник работают, LIVE возвращает 503 с понятным сообщением. Не публикуйте .env и не вставляйте токен в iOS.

```sh
curl http://127.0.0.1:8000/health
curl -X POST http://127.0.0.1:8000/api/v1/search -H 'Content-Type: application/json' -d '{"origin":"SVO","month":"2026-10","max_budget_minor":2500000,"direct_only":false}'
../.venv/bin/python -m pytest -q
```

TTL/LRU-кеш 900 секунд / 200 ключей и singleflight для одновременных одинаковых запросов. Успешный пустой ответ кешируется, ошибка не кешируется. Прошедшие предложения и пользовательские ограничения проверяются при выдаче кеша. Бюджет, прямые рейсы и режим выходных используют общий исходный ответ; точные даты и направление разделяют ключи. Разбор JSON и нормализация выполняются вне event loop; повторяющиеся записи страницы нормализуются один раз. Общий пользовательский лимит 10 запросов/минуту защищает один процесс без хранения IP или идентификаторов. Несколько workers не делят кеш и лимит; не запускайте их для этого MVP. Это локальный backend; публичное размещение с авторизацией и общим лимитером не входит в приёмку.

PARTNER_LINKS_FILE необязателен: путь к JSON точных ссылок, созданных официальным генератором. Токен/marker в URL не добавляется. См. docs/api-integration.md и docs/api-contract.md.


Конкретные даты: добавьте `departure_date` и `return_date` (`YYYY-MM-DD`), `month` должен совпадать с месяцем вылета; поездка 1–60 дней. Для месяца `weekend_only=false` включает поездки вне коротких выходных. `destination` и необязательный `destination_city_code` ограничивают направление. Полный контракт: [api-contract](../docs/api-contract.md).

`airline`, `airline_name` и `flight_number` сохраняются, если известны. Названия — локальный официальный снимок `app/airlines.json` от 04.10.2026; обновление из корня: `.venv/bin/python scripts/build_airlines.py` (1159 названий в текущем снимке). Время прибытия вычисляется клиентом по длительности, а не представляется подтверждённым полем расписания. Оператор каждого сегмента и обратная авиакомпания не гарантированы.

## Рейтинг поездки

Поиск добавляет `trip_rating`, когда сервер может рассчитать известные показатели. Без `RATING_DATA_FILE` он возвращает дорогу и известную цену билетов, а полный балл и бюджет — null. Выходные данные источника жилья должны описывать точные даты и всю группу; Open Prices и GPM не подменяют туристическое жильё. Некорректный файл отключает обогащение, сохраняя поиск билетов. Состояние доступно в `GET /api/v1/rating/status`.

Вне репозитория создайте JSON-массив объектов `DestinationData`, укажите путь в `backend/.env` и перезапустите сервер. [JSON Schema](../docs/rating-destination-schema.json) описывает контракт, [методика](../docs/trip-rating.md) — правила свежести, покрытия и ограничения. Пока проверенных данных нет, оставьте путь пустым. Не заполняйте пропуски нулями и не импортируйте синтетические тестовые цены в LIVE.

Для публичной проверки источников из корня: `.venv/bin/python scripts/probe_rating_sources.py /tmp/rating-probe.json`. Запросы ограничены 12 городами; результат содержит сводку без авторов наблюдений, доказательств и секретов. Адаптеры источников не вызываются при обычном поиске, поэтому их ошибки/таймауты не увеличивают задержку авиапоиска. Amadeus подготовлен только для тестового доступа; гостиничные цены, безопасность, сезонные условия и курсы ещё требуют подключений по методике. Кеш/ограничители локальны одному процессу.
