# Aviator

«Больше мира за меньшие деньги». Русское приложение для iPhone: аэропорт → месяц или конкретные даты и бюджет → варианты поездок → детали → избранное → поиск на Aviasales. SwiftUI / MVVM / SwiftData, iOS 17+. Backend: Python 3.12+, FastAPI, httpx, Pydantic.

## Запуск MOCK

Нужен полный Xcode 15+ с iOS 17+ SDK и установленным iPhone Simulator. Откройте **Aviator.xcodeproj**, выберите общую схему **Aviator** и iPhone Simulator, нажмите Run. Подпись для Simulator не требуется. Для MOCK установите `AVIATOR_MODE = MOCK` в Debug.xcconfig. Debug сейчас настроен на LIVE по запросу пользователя; Release использует MOCK; backend, токен и сеть не нужны, кроме перехода на Aviasales.

Десять демонстрационных направлений из SVO, до трёх поездок на каждое (до 30 вариантов). В начале месяца бюджет 25 000 ₽ даёт 21 вариант / семь направлений, быстрый фильтр 20 000 ₽ — 15 / пять; ближе к концу месяца будущих поездок может быть меньше. Цены, авиакомпании, длительность и расписание MOCK условные и обозначены DEMO. Даты строятся относительно выбранного месяца или конкретных дат. При выборе «Москва · все аэропорты» MOCK показывает те же примеры из SVO. Для других городов и отдельных аэропортов, кроме SVO, демонстрационных данных нет. LIVE поддерживает отдельный аэропорт и все аэропорты города.

## Поиск и особенность Aviator

Можно искать куда угодно, выбрать «Поездка в Европу» / «Поездка в США» или конкретный город/аэропорт назначения. При смене региона несовместимый город сбрасывается; список назначения ограничен выбранным регионом. В региональном режиме короткие выходные автоматически отключаются (можно включить снова). Европа включает Турцию и Кипр, исключает Россию и Беларусь. Региональный поиск проверяет 24 основных города Европы / 12 городов США, до 200 записей на город, четырьмя параллельными запросами в пределах 20 секунд; это подборка, а не полный список региона. Другие города можно искать отдельно. Доступны месяц (короткие выходные или любые поездки) и конкретные даты вылетов туда/обратно. Вылет — текущий месяц и следующие пять, точная поездка — от 1 до 60 дней. Бюджет — 5 000–500 000 ₽ за билеты туда-обратно на одного взрослого.

Сверху результатов есть отдельный переключатель «Сначала дешевле / Сначала дороже». По умолчанию отображаются все найденные варианты по возрастанию цены; при длинной выдаче первые 60 и кнопка «Ещё варианты». Фильтры: минимальная/максимальная цена, город/аэропорт/страна, авиакомпания, пересадки на каждом плече, длительность каждого перелёта и всей поездки, местное время вылетов и расчётных прилётов, минимальное время на месте. Можно оставить один лучший вариант на город. Изменения панели применяются кнопкой «Готово», без нового сетевого запроса. Сортировка: цена в обе стороны, ближайший вылет, меньше дороги, больше времени на месте, выгоднее час поездки.

Особенность Aviator — сравнение по времени в пункте назначения и стоимости часа поездки. Интервал считается от расчётного прилёта до обратного вылета, включая ночи, без вычета дороги из аэропорта и ожидания. «Без отпуска»: вылет в пятницу после 18:00 или в субботу, расчётный прилёт домой в воскресенье или в понедельник до 09:00. Нужно учитывать личный график и запас на дорогу.

Время вылета берётся из источника, прилёт вычисляется по длительности перелёта и явно отмечается как расчётный. Название авиакомпании — из локального официального справочника; API не подтверждает оператора каждого сегмента, обратную авиакомпанию, багаж и возвратность. Неизвестные данные не выдумываются и исключаются, если включён соответствующий фильтр. Старые снимки избранного читаются с отсутствующими новыми полями.

Для отзывчивости загрузка каталога, декодирование ответа, подготовка индекса и фильтрация вынесены из UI-потока; форматирование и подготовленные фотографии кешируются, список и сетка ленивые. Сервер переиспользует исходную выдачу при смене бюджета, прямых рейсов и режима выходных. Внешний источник по-прежнему может ждать до 20 секунд.

## Backend и LIVE

Инструкция: [backend/README.md](backend/README.md). Из корня:

```sh
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
cp backend/.env.example backend/.env
cd backend
../.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Добавьте настоящий токен только в `backend/.env`, поле `TRAVELPAYOUTS_API_TOKEN`. В `Aviator/Config/Debug.xcconfig` установите `AVIATOR_MODE = LIVE`; `AVIATOR_BASE_URL` по умолчанию — `http://127.0.0.1:8000` (в xcconfig двоеточие/слеш записаны с `$()` для защиты от синтаксиса комментария). Simulator обращается к серверу на Mac. Пересоберите приложение. При отсутствии токена backend работает, LIVE показывает ошибку конфигурации и не подмешивает MOCK.

Release принимает только HTTPS. Info-Release.plist не содержит исключений ATS. Для устройства потребуется достижимый HTTPS backend; публичный deployment не входит в MVP.

## Проверки

```sh
cd backend
../.venv/bin/python -m pytest -q
```

После установки Xcode выберите его активным (например, `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`), установите iOS runtime в Settings → Platforms и получите UUID Simulator:

```sh
xcrun simctl list devices available
xcodebuild -project Aviator.xcodeproj -scheme Aviator -configuration Debug -sdk iphonesimulator -destination 'platform=iOS Simulator,id=SIMULATOR_UUID' CODE_SIGNING_ALLOWED=NO build
xcodebuild -project Aviator.xcodeproj -scheme Aviator -destination 'platform=iOS Simulator,id=SIMULATOR_UUID' CODE_SIGNING_ALLOWED=NO test
```

Для проверок бизнес-логики на macOS 14+ из корня есть `swift run AviatorChecks` (111 проверок, не заменяет сборку и UI-проверку iPhone). `swift test` использует XCTest и также требует полный Xcode; тест сохранения SwiftData включён только в iOS target. Smoke tests используют `--ui-smoke` с фиксированным временем 01.10.2026 и временным хранилищем. Второй smoke test запрашивает увеличенный Dynamic Type. Вручную проверьте VoiceOver, размеры текста, переход и внешний поиск. Устойчивые accessibility identifiers присутствуют для поиска, карточек, избранного и перехода.

Фактический статус проверки обновляется в `docs/handoffs/aviator-mvp.md`. Первоначальная проверка выполнялась без iOS SDK. 04.10.2026 установлены Xcode 27.0 и iOS 27.0 Simulator: Debug-сборка, 9 тестов бизнес-логики и 4 UI-сценария расширенного поиска прошли на iPhone 18 Pro. Физический iPhone и ручная проверка VoiceOver пока не проверены. LIVE проверен 03.10.2026 для LED, KZN, OVB и всех аэропортов Москвы; результаты в `docs/api-integration.md`. Партнёрская атрибуция не проверена.

## Ограничения данных

Бюджет включает только билеты туда-обратно для одного взрослого в RUB. Денежный контракт — целые копейки (`price_minor`, `max_budget_minor`). Граница включительна. Возврат может попасть в следующий месяц/год. День отправления каждого плеча определяется локальной зоной соответствующего аэропорта; неизвестные пересадки не считаются прямым рейсом. Избранное хранит исходный снимок с отметкой MOCK/LIVE, не обновляет цены автоматически и блокирует переход для прошедших поездок.

Data API возвращает кешированные находки, не полный инвентарь и не подтверждение доступности. Ограничения 10 страниц/20 секунд или некорректные записи помечают выборку как неполную. Цена, багаж и класс тарифа должны быть проверены у партнёра. Endpoint не предоставляет документированной гарантии эконом-класса, поэтому LIVE предупреждает об этом. Обычная ссылка открывает эконом для одного взрослого; год отсутствует в документированном URL-формате и требует проверки у партнёра при переходе через год.

Партнёрские ссылки поддерживаются как заранее созданные в официальном кабинете точные ссылки через `PARTNER_LINKS_FILE`. Один MARKER ничего не активирует. Динамическое создание партнёрских ссылок и атрибуция не подтверждены. Подробности и источники: [интеграция](docs/api-integration.md), [контракт](docs/api-contract.md).

Фотографии и лицензии: [credits](Aviator/Resources/credits.md), доступны внутри приложения. Справочник аэропортов — локальный официальный снимок Travelpayouts от 01.10.2026; названия авиакомпаний — снимок от 04.10.2026 (`scripts/build_airlines.py`); для будущих изменений требуется обновление. Локальный backend использует один процесс: кеш и лимитер не общие между workers.

## Совместная работа

Репозиторий `flezig/aviatour` не переименован. Общая память — GitHub Issues и Project; правила [AGENTS.md](AGENTS.md), [docs/collaboration.md](docs/collaboration.md). Без авторизации GitHub временный отчёт хранится в `docs/handoffs/`, затем переносится в issue. Существующие документы других участников не изменяются.

Региональные фотографии: 20 локальных изображений основных городов Европы и США; для всех аэропортов одного города используется его фото. Источники и лицензии доступны в приложении и credits.md. Обновление: `scripts/download_regional_photos.py`.

Подробности нового экрана маршрута и план проверки актуальных цен: [docs/live-prices.md](docs/live-prices.md). Детали сегментов доступны в DEMO; текущий LIVE источник не сообщает аэропорты пересадок и их операторов. Время «Получено» — время получения кешированных данных, а не подтверждение мест. Контракт подготовлен для статусов недоступности и срока цены; живой источник ещё требуется подключить.
