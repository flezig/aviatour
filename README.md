# Aviatour

Репозиторий для совместной разработки с Codex.
Код приложения и технологический стек пока не добавлены.

## Как работаем

Задачи, решения и история работы хранятся в [GitHub Issues](https://github.com/flezig/aviatour/issues). Общая доска GitHub Projects показывает очередь и исполнителей. Правила для обоих Codex находятся в [AGENTS.md](AGENTS.md), инструкция для участников — в [docs/collaboration.md](docs/collaboration.md).

Чтобы продолжить задачу в новом чате, напишите Codex:

> Прочитай AGENTS.md и issue #N со всеми комментариями. Продолжи с последнего записанного шага.

Чтобы начать новую задачу:

> Создай issue для [описание задачи], добавь его на общую доску и выполни по правилам AGENTS.md.

Подход основан на [статье о GitHub Projects как памяти AI-агента](https://sereja.tech/blog/github-projects-ai-agent-memory/).
